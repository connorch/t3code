# Completion sound

T3 Code can play a short sound whenever an agent finishes a turn, so you can start something and
walk away without watching the sidebar.

To turn it on:

1. Open **Settings**.
2. Select **General**.
3. Under **Completion sound**, choose **Bubble** or **Pop**.

Choosing a sound plays it, so you can compare the two before settling on one. **None** is the
default and means silence.

The sound plays for every thread that finishes, across every environment the app is connected to,
including the thread you are currently reading.

The choice is stored on the device you set it on. A desktop app, a browser tab, and a phone each
keep their own setting, so you can have your laptop chime while everything else stays quiet. Some
browsers stay silent until you have clicked somewhere in the page.
